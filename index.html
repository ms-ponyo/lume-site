LUME

A web browser for iPhone.

Type a web address or a search to open any website in a tab. When you want help, hand a tab to LUME's built-in assistant and ask it to do a task on that site.

Join the beta on TestFlight

Browsing

LUME shows web pages with Apple's WebKit. Tabs and the address bar work the way you expect from a browser.

The assistant

When you hand a tab to the assistant, you can stop it or take the tab back at any time. LUME's AI features use an AI model provider you choose, with your own API key. See the privacy policy for what that sends.
